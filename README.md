#CS50X week 0 - catch the stars 
this is my week 0 project for Harvard's CS50x course
##about the project 
catch the stars is a scratch game where the player controls a character using left and right arrow keys.
the goal is to catch falling stars and reach 10 points while avoiding bombs .
##features 
-player movement 
-falling stars 
-falling bombs
-score system
-lives system
-win condition
-game over condition
-start and restart buttoms
-clones
-broadcasts
-custom My block
##technologies
-scratch
-variables
-loops
-conditions
-clones
-broadcasts
-My blocks
